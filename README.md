# 🤖 Dasar Robotika via Wokwi

> *Learning robotics, one simulation at a time.*

Selamat datang di repository **Dasar Robotika via Wokwi**.

Repository ini dibuat sebagai tempat untuk mendokumentasikan proses belajar dasar-dasar robotika menggunakan **Wokwi Simulator**. Seluruh proyek, latihan, dan eksperimen yang ada di sini menjadi catatan perkembangan selama mempelajari mikrokontroler, sensor, aktuator, dan pemrograman Arduino tanpa memerlukan perangkat fisik.

---

## Tentang Repository

Repository ini digunakan untuk:

- 🤖 Mempelajari konsep dasar robotika.
- 💡 Mencoba berbagai simulasi menggunakan Wokwi.
- 📝 Mendokumentasikan hasil praktikum dan latihan.
- 💻 Menyimpan source code Arduino.
- 📈 Melacak perkembangan kemampuan selama proses belajar.

---

## 🎯 Tujuan

- Memahami dasar elektronika dan robotika.
- Menguasai pemrograman Arduino.
- Mengenal berbagai sensor dan aktuator.
- Membuat simulasi proyek robotika secara bertahap.
- Membangun portofolio hasil belajar.
