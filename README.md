## Overview

This repository documents my learning journey in robotics and embedded systems through a collection of Arduino-based simulations developed using **Wokwi**. It serves as a personal learning portfolio that records my progress while exploring fundamental concepts in programming, electronics, and hardware interaction.

The projects included here are not intended to be complete robotics applications. Instead, they represent a series of structured exercises designed to build a strong foundation in embedded systems. Each experiment introduces a new concept and demonstrates how software can interact with electronic components to create simple yet functional systems.

One of the advantages of using Wokwi is the ability to simulate electronic circuits without requiring physical hardware. This allows rapid experimentation, easier debugging, and a more accessible learning experience while maintaining a workflow that closely resembles real-world Arduino development.

Rather than showcasing only successful implementations, this repository also reflects the learning process itself. Every project represents a milestone in understanding a new concept, solving technical problems, and gradually improving programming and engineering skills.

## Learning Methodology

Each project follows a gradual learning approach. Instead of immediately building complex systems, every exercise focuses on understanding a single concept before combining multiple concepts into larger applications.

For every topic, the typical workflow consists of:

1. Understanding the underlying electronic principle.
2. Designing the circuit in Wokwi.
3. Implementing the Arduino program.
4. Testing and debugging the simulation.
5. Documenting the implementation and key observations.

This iterative process encourages both technical understanding and problem-solving skills while reinforcing best practices in embedded systems development.
