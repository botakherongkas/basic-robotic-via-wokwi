# Dasar Robotika via Wokwi

## Deskripsi

Repository ini dibuat sebagai dokumentasi proses pembelajaran dasar robotika menggunakan **Wokwi** sebagai media simulasi. Seluruh materi, latihan, dan proyek yang ada di dalam repository ini merupakan hasil eksplorasi selama mempelajari Arduino, elektronika dasar, serta konsep-konsep fundamental dalam robotika.

Belajar robotika tidak hanya berfokus pada membuat rangkaian dapat bekerja, tetapi juga memahami alasan di balik setiap komponen, setiap baris kode, dan setiap keputusan yang diambil saat merancang sebuah sistem. Oleh karena itu, repository ini tidak hanya berisi hasil akhir, tetapi juga menjadi catatan proses belajar yang terus berkembang.

Penggunaan Wokwi memungkinkan proses eksperimen dilakukan tanpa harus memiliki perangkat keras secara langsung. Hal ini memberikan kesempatan untuk mencoba berbagai konfigurasi rangkaian, memahami cara kerja sensor dan aktuator, serta menguji program Arduino dengan lebih cepat. Kesalahan yang muncul selama proses pembelajaran juga menjadi bagian penting karena membantu memahami konsep secara lebih mendalam.

Seluruh materi disusun secara bertahap, dimulai dari konsep paling dasar seperti mengendalikan LED dan membaca input dari push button, kemudian berkembang ke penggunaan berbagai sensor, aktuator, hingga proyek sederhana yang menggabungkan beberapa komponen dalam satu sistem. Dengan pendekatan tersebut, setiap pembelajaran menjadi fondasi untuk materi berikutnya.

Repository ini juga berfungsi sebagai dokumentasi perkembangan pribadi. Setiap folder menunjukkan tahapan pembelajaran yang telah diselesaikan, sedangkan setiap proyek menjadi representasi dari kemampuan yang dimiliki pada saat proyek tersebut dibuat. Seiring bertambahnya pengalaman, isi repository ini akan terus diperbarui dengan materi, eksperimen, maupun proyek yang lebih kompleks.

Harapannya, repository ini dapat menjadi arsip pembelajaran yang bermanfaat, baik sebagai referensi ketika mengulang materi maupun sebagai portofolio yang menggambarkan proses belajar secara berkelanjutan.

---

## Tujuan

Repository ini dibuat untuk:

- Mendokumentasikan proses belajar dasar robotika.
- Menyimpan source code dan hasil simulasi menggunakan Wokwi.
- Membangun pemahaman mengenai Arduino dan elektronika dasar.
- Menjadi referensi pribadi ketika mempelajari kembali suatu materi.
- Mencatat perkembangan kemampuan dari waktu ke waktu melalui proyek-proyek yang dikerjakan.

---

## Materi

Topik yang dipelajari dalam repository ini meliputi:

- Pengenalan Arduino
- Dasar pemrograman Arduino
- Digital Input dan Output
- LED dan Buzzer
- Push Button
- Potensiometer
